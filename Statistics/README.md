# Statistics with Python
A collection of applied statistics exercises solved in Python using **NumPy**, **SciPy**, and **Matplotlib**. Each exercise pairs a real-world style problem with code, simulation, and a short written explanation.

## 📌 Topics Covered
| # | Exercise | Concept |

|---|----------|---------|

| 1 | Outlier Detective 🕵️ | Mean, median, standard deviation & effect of outliers |

| 2 | Loaded Dice Casino 🎲 | Probability mass functions (PMF) & simulation |

| 3 | Spam Filter Bayes 📧 | Bayes' Theorem & conditional probability |

| 4 | CLT With a Weird Distribution 🎨 | Central Limit Theorem, sampling distributions |

| 5 | Run Your Own A/B Test 🧪 | Hypothesis testing, t-test, statistical significance |

| 6 | Correlation Trap 🪤 | Correlation vs. causation, confounding variables |

| 7 | Build an MLE Estimator 🎯 | Maximum Likelihood Estimation, log-likelihood |

## 🛠️ Tech Stack
- Python 3

- NumPy

- SciPy

- Matplotlib

## 🚀 How to Run
1. Clone the repo:

```bash

git clone https://github.com/YOUR-USERNAME/statistics-with-python.git

cd statistics-with-python

```

2. Install dependencies:

```bash

pip install numpy scipy matplotlib

```

3. Open the notebook:

```bash

jupyter notebook statistics_exercise.ipynb

```
