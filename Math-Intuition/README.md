# Math Intuition for AI
A hands-on Jupyter notebook that builds intuition for the core math ideas behind AI and machine learning — through simple, relatable, everyday examples rather than dry formulas.

## What's Inside
| Exercise | Concept | What You'll Build |

|---|---|---|

| 1. Pixel Artist 🎨 | Matrices | Draw a 7×7 pixel-art letter and see how scalar multiplication affects brightness |

| 2. Friend Finder 👯 | Cosine Similarity | Compare "friend vectors" to find who's most alike |

| 3. My Restaurant Brain ⚖️ | Dot Product / Weighted Scoring | Rank restaurants using personal weight preferences |

| 4. Chai Quality Inspector ☕ | Z-Scores & Anomaly Detection | Build a mini fraud-detector skeleton |

| 5. Mood Detector Neuron 🤖 | Sigmoid Neuron | Detect "angry" messages using a single artificial neuron |

| 6. Temperature Knob 🌡️ | Softmax & Temperature | Discover how temperature controls model confidence |

| 7. Grow the Search Engine 🔎 | Embeddings & Semantic Search | Build a tiny top-k document search function |

| 8. Attention Detective 🕵️ | Attention Mechanism | Explore how attention weights shift between words |

## Why This Notebook
Most explanations of AI math jump straight into equations. This notebook instead ties each concept to something intuitive and personal — friends, food, chai, moods — so the *why* behind vectors, similarity, probability, and attention actually sticks.
