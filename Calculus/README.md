# Calculus Exercises
A collection of calculus exercises solved and visualized using Python. Each exercise focuses on

building intuition for core calculus concepts through numerical computation and plots, rather

than pure symbolic math — with several exercises connecting calculus directly to machine

learning fundamentals like gradient descent.

## 📘 What's inside
- **Numerical derivatives** — computing slopes at given points and identifying critical points

- **Gradient descent** — visualizing convergence from multiple starting points

- **Learning rate experiments** — observing how different learning rates affect training stability

- **Loss function behavior** — plotting and analyzing optimization paths

## 🛠️ Requirements
- Python 3

- NumPy

- Matplotlib

Install dependencies:

pip install numpy matplotlib
## ▶️ Usage
Open the notebook in Jupyter:

jupyter notebook Calculus\_exerces.ipynb
Or open it directly on GitHub — it renders automatically.
